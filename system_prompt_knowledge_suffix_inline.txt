## Knowledge base

The following memories are procedures and facts distilled from verified past runs in this exact environment. They are provided directly — no tool call is needed to access them.

### How to use
- Each memory is one lesson for one specific scenario. Its title reads `<service>: <task>`. Its "How do I …?" names the task the lesson teaches; some memories also have "Or when: …", the signal that shows the scenario mid-run (an error, an empty result, a field value).
- **At the start:** before your first tool call, scan the memories below and identify every memory whose "How do I" part matches the user's request.
- **Mid-run:** after each tool result, check it against the memories' "Or when" signals, and apply any matching memory.
- Where a memory covers a step, treat it as reliable and prefer it over your own assumptions. Apply it only within the scope it names.
- Absence of coverage is not a restriction: if no memory applies, proceed normally.
